# Northwind Traders - Global Trade & Product Performance Dashboard

An enterprise-grade, interactive Power BI dashboard designed to transform raw operational data into actionable business intelligence, tracking core financial metrics, regional sales dynamics, and comprehensive product performance.

## 📊 Project Overview
The **Northwind Traders Dashboard** provides a holistic view of supply chain and sales operations. By leveraging advanced data modeling and dynamic DAX measures, the report enables stakeholders to explore deep commercial insights without clutter, maintaining a clean and professional user experience across all reporting pages.

* **Executive Summary:** High-level performance indicators, dynamic narrative insights, and core business metrics consolidated into a single intuitive view.
* **Regional Analysis:** Geographical breakdown of sales, shipping performance, and market penetration across different territories.
* **Product Performance:** Detailed evaluation of top-selling categories, inventory trends, and profitability drivers.

## 🛠️ Tech Stack & Architecture
* **Power BI Desktop:** Core tool for ETL processes, data cleaning, relationship modeling, and custom UI/UX design.
* **DAX (Data Analysis Expressions):** Utilized for creating complex calculated columns, dynamic measures, and real-time textual summaries.
* **Git & GitHub:** Version control, tracking project iterations, and collaborative documentation.

## 🚀 How to Run & Explore
1. Clone or download this repository directly to your local machine.
2. Ensure you have **Power BI Desktop** installed.
3. Open the project file to explore the interactive filters, drill-through capabilities, and underlying data relationships.
